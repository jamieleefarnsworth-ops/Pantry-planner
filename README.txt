Important:
A real installable PWA must be served from HTTPS (or localhost). It will not install from a local file:// URL.

After uploading this folder to any static HTTPS host, open index.html/site URL in Chrome on Android.
Then use the in-app "Install app" button when it appears, or Chrome menu > Add to Home screen / Install app.

The app stores Pantry Planner data locally in the browser/device using localStorage.
